npm create vite@latest 프로젝트명
  press r + enter to restart the server
  press u + enter to show server url

npm run dev : 작성하는 코드가 실시간으로 반영됨(개발 시 사용)

npm run build : 서버에 올려서 사용자들에게 웹페이지로 배포될 파일들을 코드를 모아 컴파일
